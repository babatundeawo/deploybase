Overview

Students tap a colour. Teachers see the truth. Nobody sees more than they should.

ClassPulse National takes the simple feedback idea from Ivan’s earlier offline app and rebuilds it as a real, hosted platform for any school in Nigeria, with accounts, roles, and data that survives between devices.

The Class Offering

Every Class or Arm plus Subject pair is a Class Offering, created automatically the moment a Class or Arm is added, using the 2025 NERDC reform curriculum for that level. One Class Offering can only ever belong to one teacher.

Privacy by design

Teacher facing queries only ever return aggregate counts and scores. The database is structured so a teacher can never see a student’s identity sitting next to their colour vote.

Three kinds of codes

A permanent School Head Portal Code, shared Teacher and Student Entry Codes that act as gate passes, and long, unguessable Personal Codes issued to each individual only after approval.

Approval workflows

Every new teacher and every new student registration sits in a pending list until the right person approves it: the School Head for teachers, and each subject’s own teacher for students.

How a tutoring session runs

Mr. Babatunde and Ivan drive the whole build with one command

There is no status file to keep updated between sessions. Progress is tracked purely by the class number typed next, and Claude always teaches one step at a time, waiting for confirmation before moving on.

Non negotiable rules

What the tutor never compromises on

01

One step at a time

Explain in plain English before every code block, and wait for confirmation before moving on.

02

Child friendly design in every step

Large buttons of at least 56px, friendly language, colour paired with text, the Nunito font, navy plus bright accents, and no layout overflow at any width down to 375px.

03

Never rewrite whole files

Show only the new code for the current step, with the exact file and location named.

04

Teacher queries only ever aggregate

Flag this explicitly whenever a query is written that a teacher will run, since it must never expose an individual student’s vote.

05

Keep code types conceptually distinct

Entry codes are shared gate passes in a word plus two digit format. Personal codes are private, unique, and only issued after approval, in a two word plus four digit format.
