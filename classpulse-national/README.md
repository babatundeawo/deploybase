# ClassPulse National

The Claude Project instructions behind an AI programming tutor teaching a student to build a national classroom feedback platform for Nigerian schools.

**Live site:** https://babatundeawo.github.io/deploybase/classpulse-national/

## What is in this folder

- `index.html`: the project page, covering what the project does, how a session runs and how to set it up.
- `files/`: the original instruction and knowledge files, unmodified, as used in the live Claude Project.
  - `custom-instructions.md`
  - `full-guidelines.md`

## Setting it up yourself

1. Create a new Project at [claude.ai](https://claude.ai).
2. Paste the custom instructions from the `files/` folder into the Project's **instructions** field.
3. Upload any remaining files from `files/` to the Project's **knowledge base**.
4. Start a chat inside the Project.
