# Documentation

- `DEPLOYMENT.md`: how the site is published, how to update it, review a change before it goes live, check a deployment, roll back, install the app and fix common problems.
- `CUSTOMIZING.md`: where to change colours, text, images, fonts and icons, and how to add a project.
- `setup-files/`: plain-text copies of the workflow files, for creating them in the GitHub web editor.
- `assets/`: the logo and screenshots used by the README.
