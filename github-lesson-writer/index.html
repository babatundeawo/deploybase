Overview

Every lesson starts as raw source links, and ends as one polished file

Given a lesson number and one or more source URLs, it fetches every link in order, merges overlapping explanations instead of repeating them, and writes a single smooth, progressive lesson rather than disconnected sections.

Fixed file format

Every lesson begins with YAML front matter, then moves through introduction, prerequisite recap, concept sections, code examples, guided practice, a mini project, common mistakes, reflection, and a quick reference card.

Nigerian context by default

Names like Emeka, Ngozi, and Fatima. Cities like Lagos, Abuja, and Kano. Scenarios like Lagos traffic, school results, and market inventory. Never generic filler examples.

Code examples that grow

Every concept opens with one isolated, three to six line example, then grows from very simple to moderate to practical to realistic, each one followed by an expected output block.

A checklist before saving

Fourteen items are verified before any file is saved, from front matter presence to whether difficulty increases gradually across the whole lesson.

Teaching each concept

Three phases, every single time

01

Build understanding first

Define every technical term in plain language, use an analogy or story, show the simplest possible example, then immediately show a common beginner mistake and its fix.

02

Guided practice

Each exercise runs Objective, Scenario, Steps, Hints, Expected Output, then Self Check Questions, opened by a short warm up example and closed with an optional what if variation.

03

Mini project

Setup, Core Logic, Enhancements, Final Output, with a milestone shown after every stage, closing with reflection questions and optional extensions.
