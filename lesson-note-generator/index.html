What changed

Same jobs, one Project, a cleaner setup

The instructions behind these two tools have been rewritten and merged into a single Master Project Instructions document. Set the Project up once, upload the Scheme of Work files that match what you teach, and the same Project produces either document, no switching, no duplicated setup.

Say a Week number

Weekly lesson notes

Ask with a Week number and the Project fetches real term dates, works out mode automatically, and writes a full nine-part lesson note booklet.

Say a Term only

Exams & revision files

Ask with just a Term, no week number, and it builds a 70-mark exam with a separate marking guide, or a self-study revision file instead.

New in this version

A Scheme of Work picker

117 small files, one per Class + Subject, so teachers download only what they actually teach instead of one document covering the whole school.

Every step, from creating the Project to the interactive Master Instructions editor and the file picker, now lives on its own dedicated site. This registry page just points you there, rather than keeping a second, slower-to-update copy of the setup flow.
