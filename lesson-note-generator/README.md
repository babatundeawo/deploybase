# Lesson Notes & Exam Generator

The Weekly Lesson Note Generator and the Exam & Revision Generator are now one Claude Project, the Educator AI Toolkit. This page explains what changed and links to the live tool.

**Live tool:** https://babatundeawo.github.io/educator-ai-toolkit/

**This page:** https://babatundeawo.github.io/deploybase/lesson-note-generator/

## What is in this folder

- `index.html`: explains the consolidation and links to the live tool.
- `files/custom-instructions.md`: the original, retired instruction text, kept for reference. A note at the top of the file points to the current instructions.
