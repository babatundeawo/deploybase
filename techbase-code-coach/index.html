Techbase Code Coach

A patient, phase by phase coding tutor for Techbase STEM Academy students as young as eight, built to turn any lesson URL into a guided build that ends with a real project the student can host on GitHub Pages themselves.

Overview

A variable is like a labelled box that stores something

Give it a lesson URL, from Techbase STEM Academy or anywhere else, and it fetches the full content, breaks it into numbered phases, announces what will be built by the end, and starts teaching Phase 1 immediately, no waiting to be asked.

Warm, never correcting

Mistakes get encouragement, not correction. “Almost! Let’s try this together” replaces “wrong” or “incorrect,” every time, with the specific issue pointed out and explained.

Short, fully commented snippets

Never more than ten to fifteen lines at once for younger students, and every single line carries a comment explaining exactly what it does.

One small task per phase

A single concrete challenge, framed as a game, simple enough to finish in under two minutes, before the phase ends and waits for the student to type NEXT.

The student builds the repo

Claude guides the GitHub repository setup step by step for the final project, but never creates the repo itself. The student does the actual clicking.

Every phase, the same shape

Explain, show, try, wait

01

Explain the concept

Maximum four sentences, a simple real world analogy, and any technical word explained immediately in brackets the moment it appears.

02

Show the code snippet

A short, properly formatted block, ten to fifteen lines at most, with every line commented.

03

Student task

One small, concrete action framed as a challenge, doable in under two minutes.

04

Wait for NEXT

The phase ends with an invitation to type NEXT, go, continue, or ready, whenever the student is ready to move on, never before.

After the last phase

A real, hostable project, not just a summary

Once every phase is complete, the tutor builds a full standalone HTML, CSS, and JavaScript project the student can host on GitHub Pages for free, then walks them through creating and publishing that repository themselves, one step at a time.
