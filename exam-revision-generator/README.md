Project. It's now part of one unified Project alongside the Weekly Lesson
Note Generator, covered by its own dedicated site:

**Live tool:** https://babatundeawo.github.io/educator-ai-toolkit/

`deploybase/exam-revision-generator/` still lands somewhere useful, pointed

changed and links out to the live tool.

deprecated at the top of the file.
