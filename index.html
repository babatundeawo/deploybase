How it works

Rebuild any deployment in three steps

Each project page holds the original files, unmodified. You need a Claude account and a few minutes.

  1. Pick a deployment

    Open a card above and read the overview, how a session runs and the rules the system never breaks.

  2. Copy the files

    In the Get this project section, open a file and choose Copy text, or use the link to the raw file.

  3. Paste into a Project

    Create a new Project at claude.ai, paste the custom instructions into its instructions field and upload the guidelines file to its knowledge.

This registry grows over time. Every deployment here is a Claude Project with its own instruction set, purpose and audience. Some are ongoing workflows, one is a live public tool. New entries are added as new systems go into use, so bookmark this page rather than any single deployment.
